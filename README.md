# Chess.com rating converter
Chess.com rating converter! Converts to Lichess, USCF, and FIDE!

This was meant to introduce me to the requests module, flask, and APIs! Just input your chess.com name and let the code figure out estimated FIDE, Lichess, and USCF scores!
